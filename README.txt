# ThoughtInbox

ThoughtInbox is a desktop application designed to capture ideas the moment they occur, helping users build a searchable, organized archive of thoughts instead of letting them disappear.

Built with Python, CustomTkinter, and SQLite, the project focuses on creating a fast, distraction-free experience for recording and organizing thoughts. The long-term goal is to expand it into an intelligent personal thought management system with features such as reminders, tagging, search, and AI-powered organization.

## Features (Current)

- Save thoughts locally
- View previously saved thoughts
- SQLite database for persistent storage
- Edit and delete thoughts
- Search thoughts
- Dark/light themes
- Persistent Settings
- Export thoughts in md, txt and json formats
- Undo delete
- Favorites
- Tags
- Thought filtering
- Autosave

## Planned Features

- Reminder scheduling
- Desktop notifications
- Semantic search
- Encrypted thought storage

## Tech Stack

- Python
- CustomTkinter
- SQLite
- Git

## Getting Started

### Clone the repository

```bash
git clone <repository-url>
```

### Install dependencies

```bash
pip install customtkinter
```

### Run

```bash
python main.py
```
